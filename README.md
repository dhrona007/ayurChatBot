## 🚀 Quick Start

_Get running in 60 seconds!_

# 1. Clone the repository (because good things come in packages)

```bash
git clone https://github.com/yourusername/ayurbot.git && cd ayurbot
```

# 2. Install dependencies (the secret sauce)

```
pip install -r requirements.txt
```

# 3. Power up the AI 🔌

```
echo "GEMINI_API_KEY=your_google_gemini_api_key" > .env
```

# 4. Launch!

```
python app.py
```

🌍 **Open your browser to** → `http://localhost:5000`
